# Contador de Dias 📅

Um contador de dias simples e motivador com versículos bíblicos!

## 🎯 Funcionalidades

- ➕ Adicionar um dia
- ➖ Remover um dia
- 🔄 Zerar o contador
- 🎉 Mensagens motivacionais a cada 30 dias
- 🙏 Versículos bíblicos ao completar um ano

## 🚀 Como usar

1. Abra o arquivo `index.html` no seu navegador
2. Clique nos botões para alterar o contador
3. Receba mensagens de motivação conforme avança!

## 📱 Compatibilidade

Funciona em todos os navegadores modernos (Chrome, Firefox, Safari, Edge).
